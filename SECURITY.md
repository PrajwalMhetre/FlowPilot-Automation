# Security Policy

## Reporting

Please do not disclose vulnerabilities in public issues. Contact the repository maintainer privately through the GitHub profile and include reproduction steps, impact, affected components and any safe proof of concept.

## Supported scope

- Public lead intake
- Owner CRM and authorization
- Supabase database access and Edge Functions
- Vercel deployment configuration

## Responsible disclosure

Allow time for triage and remediation before public disclosure. Do not access, modify, export or retain other people's lead data during testing.
